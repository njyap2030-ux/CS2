# Assignment Tracker
This is a simple Assignment Tracker made using Python. It lets users add assignments, view tasks, mark assignments as done, and delete tasks. The program uses a menu system and runs in the terminal.

## Description
This program helps users organize their assignments by allowing them to add tasks, view deadlines, mark work as done, and delete completed or unwanted tasks. It is a beginner-friendly project made to practice basic Python programming skills.

## Features
- Add new assignments with a deadline
- Show all saved assignments
- Mark assignments as done
- Delete assignments
- Simple menu interface

## How to Run the Program
1. Make sure you have Python installed.
2. Download the file `assignment_tracker.py`.
3. Open a terminal or command prompt.
4. Run the program by pressing F5 or clicking 'Run' 
5. Follow the on-screen instructions to enter student names and grades.
